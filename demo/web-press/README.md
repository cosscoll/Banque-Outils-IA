# THE WEB PRESS — Studio Web 3D

Original proof-of-concept for Banque Outils IA. Real Blender-manufactured letterpress model, Cycles renders, glTF animation and interactive Three.js display, built without commercial assets. Source: `scripts/build_webpress.py`; assets generated by GitHub Actions.

## Test and build
`blender -b -t 4 --python scripts/build_webpress.py -- --out web/assets --samples 20 --size 1000`
Expected outputs: `web-press-original.blend`, `web-press-original.glb`, four `XX-*.png` renders.
Serve `web/` over HTTP for WebGL mode; model and images load relative to the directory. JS modules for Three.js are delivered via jsDelivr CDN; offline visitors see static Cycles renders. WebGL material rendition must be reviewed on an actual GPU browser and is **not** assumed passed by Actions smoke tests.
