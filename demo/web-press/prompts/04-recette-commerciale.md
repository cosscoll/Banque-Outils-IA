# THE WEB PRESS — Prompt 04 / QA et test de commercialisation

Teste le projet [URL] comme si tu livrais un site de studio créatif. Vérifie build, réponse HTTP de l'URL publique après déploiement, console et 404, WebGL réel, matériaux et transparence sous plusieurs angles, 5 positions de scroll, responsive 360 / 390 / 768 / 1440px, pointer/touch/clavier, reduced motion, FPS et stratégie basse puissance.

Prends des captures VRAIES du GPU et une courte vidéo. Si la machine est montrée seulement en image de secours, marque GPU NON VÉRIFIÉ. Ne prétends pas au niveau Igloo/Noomo sans revue esthétique humaine.

Prépare pour le kit vendable : code original, .blend + .glb originaux, prompts 01 à 04, notices de licences, variantes, README et guide débutant. Organise un test où une personne novice réalise un deuxième site (autre secteur) avec le seul kit. Identifie toute intervention manuelle ou dépense nécessaire. Ne valide pas commercialement avant ce test.
