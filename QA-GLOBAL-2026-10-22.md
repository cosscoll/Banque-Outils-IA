- **13 pages HTML** contrôlées : accueil, produits, contact, catalogue, méthodes, parcours, avancement et six showrooms.
- **304 attributs href** analysés. Aucun chemin de page locale manquant dans les 13 pages contrôlées.
- **48 liens d'ancrage internes** vérifiés : toutes les cibles référencées existent dans les pages source.
- **Six showrooms** : chacun contient trois supports en perspective, trois panneaux de contenu, une démonstration textuelle locale et une navigation de retour.
- **13 ressources de styles et scripts critiques** (anciens et nouveaux) vérifiées dans GitHub : toutes présentes et accolades CSS équilibrées. Le JavaScript showroom se compile.
- **Interactions simulées sur les fichiers actifs** : showroom 7/7 (état initial, sélection, désélection, survol, sortie, démo, remise à zéro) ; menu mobile et préparation de contact 4/4 (ouverture, fermeture Escape, fermeture extérieure, lien GitHub de brouillon).
- **Publication** : le dépôt est sur `main` avec les derniers changements enregistrés ; la réussite de GitHub Pages et le rendu sur les appareils réels restent **non confirmés**.

## Défauts confirmés et corrigés

1. `scripts/check-conversion-ux.mjs` ne se compilait pas : expressions régulières incorrectement échappées dans les tests des six showrooms. Le bloc est remplacé par des contrôles valides ; les tests sont désormais syntaxiquement exécutables.
2. La suite UX vérifie maintenant que les fichiers CSS et JS liés par les pages existent et que les scripts locaux et inline sont syntaxiquement valides, afin d'éviter de perdre ce contrôle lors de nouveaux produits.
3. `assets/product-showroom.js` permettait au survol de remplacer temporairement le support explicitement sélectionné. Le choix reste maintenant verrouillé jusqu'à désélection. Les six pages utilisent une nouvelle version de l'URL JS pour éviter les caches.
